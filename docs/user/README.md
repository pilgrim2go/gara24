# Hướng dẫn sử dụng

Gara24 chạy trên trình duyệt, dùng được trên điện thoại, máy tính bảng và máy tính. Mỗi người chỉ thấy nút và số liệu đúng với vai của mình.

Đọc trước: [Làm quen màn hình](bat-dau.md) (mở phần mềm, đọc bảng điều phối, trang chi tiết lệnh).

## Hướng dẫn theo vai

| Vai | Việc chính trên phần mềm |
| --- | --- |
| [Cố vấn dịch vụ](vai/co-van.md) | Tiếp nhận xe, báo giá, chuyển bước, thu tiền QR |
| [Thợ](vai/tho.md) | Bắt đầu sửa, báo chờ, báo xong để kiểm tra |
| [Thủ kho](vai/thu-kho.md) | Xuất phụ tùng cho lệnh đã duyệt |
| [Thu ngân](vai/thu-ngan.md) | Thu tiền bằng mã QR |
| [Quản lý](vai/quan-ly.md) | Điều phối xưởng, kiểm tra xe, hủy và mở lại lệnh, xem báo cáo |
| [Chủ gara](vai/chu-gara.md) | Mọi việc của quản lý, theo dõi lãi từng lệnh |
| [Kế toán](vai/ke-toan.md) | Xem báo cáo ngày, đối chiếu tiền và kho, xem nhật ký |
| [Nhà đầu tư](vai/nha-dau-tu.md) | Chỉ xem: lệnh, lãi, báo cáo |
